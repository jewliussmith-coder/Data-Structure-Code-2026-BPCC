Phase 3

A poison message starts in the main queue with a retry count of 0. Each time processing fails, its retry count increases and it is moved to the back of the main queue. This allows other messages to be processed before it gets another attempt. Once the message reaches the maximum retry limit, it is removed from the main queue and placed into the Dead-Letter Queue. The message keeps its retry count and other information when it enters the DLQ, where it can be viewed and cleared.
