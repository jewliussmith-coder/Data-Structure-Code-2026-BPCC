Phase 3

I find the recursive solution more intuitive because it is shorter and naturally follows the structure of the file system. The iterative solution uses an explicit stack, which requires more code, but it avoids recursive call overhead and does not depend on the program's runtime call stack. Both approaches use extra space to keep track of folders that still need to be visited, but the stack version gives more direct control over that process. For this project, I would prefer the recursive version because I find it easier to read and maintain.
